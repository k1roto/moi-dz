1.Поле "Имя пользователя" (Только Кириллица, 1-255 символов)
Тесты которые должны сработать:
Имя из 1 буквы, Имя из 255 букв и обычное имя средней длины - Кирилл
Тесты которые не должны сработать:
Поле имя пустое, имя из 256 букв, имя не на кириллице "Kirill",имя с цифрами или символами
2. Поле пароль (Только цифры и 1-64 символов)
Тесты которые должны сработать:
Пароль из одной цифры, пароль из 64 цифр, обычный пароль
Тесты которые не должны сработать:
Поле пароль пустое, пароль из 65 цифр, поле пароль заполнено символами или цифрами с символами.
3. Дата рождения (Формат дд.мм.гггг., строго 18+)
Тесты которые должны сработать:
Ровно 18 лет граница допуска 09.08.2026 (сегодняшнее число), старше 18 лет
Тесты которые не должны произойти:
Нет 18 лет, пустое поле, неверный формат даты, несуществующая дата
4. Поле электронный адрес (Необязательное, до 255 символов, формат имя@домен.ру
Тесты которые должны сработать:
Пустое поле (так как оно не обязательное), стандартная почта до 255 символов, правильная форма почты
Тесты которые не должны сработать:
Почта более чем 255 символов, нарушен правильный формат почты например нет домена или @
